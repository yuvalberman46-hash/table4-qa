# שולחן 4 - אפליקציית שאלות ותשובות (PWA)

גרסת האפליקציה של הכלי - אפשר לפתוח מהטלפון ולהתקין על מסך הבית, בלי
PowerShell ובלי טרמינל. כוללת שתי תוספות מעבר לגרסת המחשב:

1. **ציון דקה מדויקת** - כל תשובה מציינת גם באיזה פרק וגם באיזו דקה בתוכו
   המידע נאמר, עם קישור שפותח את היוטיוב בדיוק באותו רגע.
2. **עדכון שבועי אוטומטי** - בכל שבת האפליקציה בודקת בעצמה אם עלה פרק חדש
   לערוץ, ואם כן - שולפת ומוסיפה אותו למאגר לבד, בלי שתצטרכו להריץ שום דבר.

## שלב 0 (חובה, פעם אחת): עדכון מסד הנתונים

כדי שציון הדקה יעבוד, מסד הנתונים ב-Supabase צריך עמודה נוספת. **אם עוד לא
עשיתם את זה:**

1. היכנסו ל-Supabase, לפרויקט שלכם, ל-**SQL Editor**.
2. פתחו את הקובץ `schema_update_timestamps.sql` שנמצא בקובץ ה-ZIP של
   הכלי לשליפת התמלולים (table4-automation), העתיקו את כל התוכן, הדביקו
   ב-SQL Editor, ולחצו **Run**.

זו תוספת בלבד (לא מוחקת כלום). בלעדיה האפליקציה עדיין תעבוד, אבל בלי ציון
דקה.

## מה יש כאן

- `app.py` - שרת קטן שגם עונה על שאלות (`/api/ask`) וגם בודק ומוסיף פרקים
  חדשים (`/api/update-index`).
- `table4_common.py` - כל הלוגיקה המשותפת (זהה לזו שבכלי הדסקטופ).
- `static/` - עמוד האינטרנט עצמו (מה שרואים בטלפון), כולל אייקון לאפליקציה.
- `requirements.txt`, `render.yaml` - קבצי הגדרה שאומרים לשירות האחסון איך
  להריץ את זה.

## שלב 1: להעלות את הקבצים ל-GitHub

GitHub הוא אתר חינמי לאחסון קוד. שירות האחסון (Render, בשלב הבא) קורא
משם את הקבצים.

1. גשו ל-[github.com](https://github.com) ואם אין לכם חשבון - לחצו
   **Sign up** ופתחו אחד (חינמי, רק כתובת מייל וסיסמה).
   אם כבר יצרתם מאגר `table4-qa` בעבר - דלגו לסעיף "עדכון" בתחתית הקובץ
   הזה במקום להמשיך כאן.
2. בפינה הימנית העליונה לחצו על סימן ה-**+** ואז **New repository**.
3. תנו לו שם, למשל `table4-qa`, ולחצו **Create repository**.
4. בעמוד שנפתח לחצו על **uploading an existing file** (או: **Add file**
   > **Upload files**).
5. **חלצו קודם את קובץ ה-ZIP** שקיבלתם למחשב (לחיצה ימנית > Extract All),
   כך שיהיה לכם תיקייה בשם `table4-app` עם כל הקבצים בפנים.
6. גררו את **כל התוכן שבתוך** התיקייה `table4-app` (את `app.py`,
   `table4_common.py`, `requirements.txt`, `render.yaml`, ואת כל תיקיית
   `static`) לתוך אזור ההעלאה בדפדפן.
7. גללו למטה ולחצו על הכפתור הירוק **Commit changes**.

## שלב 2: לפרוס (deploy) ב-Render

1. גשו ל-[render.com](https://render.com) ולחצו **Get Started** / **Sign Up**.
   הכי פשוט להתחבר עם **Sign up with GitHub**.
2. בלוח הבקרה, לחצו **New** ואז **Blueprint**.
3. בחרו את המאגר `table4-qa`. Render יזהה אוטומטית את `render.yaml`.
4. הוא יבקש מכם למלא שישה ערכים (environment variables):
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `VOYAGE_API_KEY`
   - `ANTHROPIC_API_KEY`
   - `YOUTUBE_API_KEY` - **אותו מפתח** שהגדרתם בעבר בשביל `fetch_episodes.py`.
   - `UPDATE_SECRET` - קוד סודי משלכם, שרק אתם (ואני) יודעים - מגן על
     נקודת העדכון השבועי כדי שאף אחד אחר לא יוכל להפעיל אותה. אפשר להשתמש
     בזה:
     ```
     -a1oGQ3HsqknyaUkFO6YJne5N0kQ0Pe7
     ```
     או כל מחרוזת אחרת שתבחרו - רק תזכרו/שמרו אותה, תצטרכו לתת לי אותה
     בסוף כדי שאוכל לתזמן את הבדיקה השבועית.

   מלאו את כל השישה, ולחצו **Apply** / **Create**.
5. Render יתחיל לבנות ולהריץ. אפשר לעקוב בלוג שמופיע על המסך. כשמופיעה
   ההודעה **Live** (בירוק) - סיימתם.
6. בראש העמוד תראו כתובת, בסגנון `https://table4-qa.onrender.com`. זו
   כתובת האפליקציה שלכם.

## שלב 3: לפתוח בטלפון ולהתקין

1. פתחו את הכתובת מהשלב הקודם בדפדפן של **הטלפון**.
2. נסו לשאול שאלה כדי לוודא שהכל עובד - התשובה אמורה להציג "צ'יפים"
   לחיצים עם שם הפרק והדקה, שפותחים את היוטיוב בזמן המדויק.
3. **להתקנה על מסך הבית:**
   - **אנדרואיד (Chrome):** שלוש נקודות בפינה > **התקן אפליקציה**.
   - **אייפון (Safari):** כפתור השיתוף > **הוסף למסך הבית**.

## שלב 4: הפעלת העדכון השבועי האוטומטי

זה החלק שאני (קלוד) עושה, לא אתם - אחרי שהאפליקציה שלכם חיה (Live) ויש
לכם את הכתובת שלה ואת ה-`UPDATE_SECRET` שבחרתם, **תעתיקו ותשלחו לי כאן
בצ'אט את שני אלה**, ואני אגדיר תזמון קבוע (כל שבת) שיבדוק אם עלה פרק
חדש ויוסיף אותו לבד.

אם תרצו לבדוק את זה ידנית בעצמכם באמצע, אפשר לפתוח בדפדפן (במחשב, לא
צריך טלפון):

```
https://<הכתובת-שלכם>.onrender.com/api/update-index?secret=<UPDATE_SECRET שלכם>
```

זה יחזיר תשובת JSON שאומרת אם נמצא פרק חדש ומה קרה איתו (או רשימה ריקה
אם אין פרק חדש כרגע).

## דברים שכדאי לדעת

- **השירות החינמי "נרדם"** אחרי 15 דקות ללא שימוש - פתיחה ראשונה אחרי
  הפסקה לוקחת עד כ-30-60 שניות. זה תקין. (הבדיקה השבועית האוטומטית
  "מעירה" אותו בעצמה, אין צורך שתהיה פתוחה מראש.)
- **פרק חדש לא בהכרח יהיה מתומלל בעברית מיד כשהוא עולה** - לפעמים לוקח
  ליוטיוב זמן לייצר כתוביות אוטומטיות. אם הבדיקה השבועית לא מוצאת תמלול,
  היא פשוט תנסה שוב בשבוע הבא.
- אם תרצו לעדכן את הקוד בעתיד (גרסה חדשה שאני אשלח), מעלים את הקבצים
  המעודכנים לאותו מאגר ב-GitHub (**Add file > Upload files**, עם אישור
  Replace) - Render בונה ופורס מחדש אוטומטית תוך דקה-שתיים.
- הכתובת של האפליקציה פומבית (מי שיש לו את הקישור יכול לפתוח) אבל לא
  מפורסמת בשום מקום. נקודת העדכון השבועי מוגנת בנוסף בקוד הסודי.
